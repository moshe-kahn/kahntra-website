# Kahntra

Source for [kahntra.com](https://kahntra.com/tech), my portfolio of
human-centered software: The Moments Collection (Momo Movies,
ListenLab, Momentum Management, and further concepts), the Momo
Editions poster gallery, and a small decision-engine demo that ranks
generated design studies against a target profile.

Hand-built as a static site: semantic HTML, CSS, and vanilla
JavaScript. No framework, no build step.

Designed and built by Moshe Kahn, with an AI-assisted development
workflow (Codex).
